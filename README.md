#📊 Project Overview

The Impact of Generative AI on Academic Performance and Student Well-being

This repository contains our collaborative group capstone project for the Junior Data Analytics program at NPower Canada.

Working as an Agile team (Scrum Group 6), our objective was to analyze a dataset of 50,000 students to uncover the true academic and psychological impact of Generative AI tools in higher education. Going beyond simple usage statistics, our team utilized Python, SQL, and Power BI to mathematically prove how different AI use cases correlate with GPA growth, skill retention, and exam anxiety across various academic disciplines.

Key Technologies Used by the Team:

Python (Pandas): Data cleaning, handling null values, and feature engineering (calculating GPA trajectories).
SQL (SQLite): Database architecture and querying complex demographic trends.
Power BI: Interactive dashboard design and visual storytelling to present actionable business recommendations.
Git & GitHub: Version control and collaborative code management.
Ultimately, this project proves that while AI can provide a slight boost to grades when used as a debugging tutor, over-reliance leads to a severe drop in long-term skill retention and a spike in closed-book exam anxiety.
